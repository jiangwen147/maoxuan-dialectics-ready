# 毛选事件分析导师

这是一个 Codex Skill，用《毛选》中的方法论来引导用户分析现实事件、社会现象、个人困境和人际矛盾。

它不是直接输出一段结论，而是先和用户建立互动：先问用户怎么看，再根据用户的判断指出哪些地方合理、哪些地方片面，然后结合《实践论》《矛盾论》等方法一步步引导用户形成更扎实的分析能力。

## 适合用来分析什么

- 热点事件和社会争议
- 青年就业、躺平、内卷等现实问题
- 工作、家庭、人际关系中的具体矛盾
- 乡村振兴、集体主义探索、基层治理等议题
- 想用毛泽东思想方法论理解现实的问题

## 核心流程

当用户提出一个事件或问题后，skill 会先给出 3-4 个常见主流观点选项，并附带一个自定义选项：

```text
我先不急着下结论。你更接近下面哪种看法？

1. ...
2. ...
3. ...
4. ...
5. 我有自己的看法，手动输入。

你直接回数字就行；如果选 5，就把你的判断写出来。
```

用户选择后，skill 会按这个顺序回应：

1. 先肯定用户观点中合理、贴近现实的部分。
2. 再指出其中片面化、情绪化、静止化、抽象化的地方。
3. 结合一个《毛选》方法论概念进行解释。
4. 把方法重新落回具体事件。
5. 最后提出一个追问，引导用户继续调查和思考。

## 方法论重点

这个 skill 重点使用这些分析方法：

- 没有调查就没有发言权
- 实践是认识的来源和检验标准
- 具体问题具体分析
- 抓主要矛盾
- 分清矛盾的主要方面
- 区分现象和本质
- 分析内因和外因
- 从群众中来，到群众中去

## 安装方式

把本仓库作为 skill 放入你的 Codex skills 目录中，例如：

```text
~/.codex/skills/maoxuan-dialectics-ready/
```

目录结构应类似：

```text
maoxuan-dialectics-ready/
├── SKILL.md
└── agents/
    └── openai.yaml
```

## 使用示例

你可以这样触发：

```text
用毛选方法分析一下中国官方反对躺平，但很多年轻人反感官方说法。
```

也可以分析个人处境：

```text
我原来是土木工程的，行业不行，现在想转 AI 视频创作，用毛选方法帮我分析一下。
```

## 设计目标

这个 skill 的重点不是替用户背理论，也不是给用户灌输固定答案，而是帮助用户形成一种思考习惯：

- 先调查事实，再形成判断。
- 先抓具体矛盾，再谈抽象原则。
- 既看到个人选择，也看到现实条件。
- 既肯定用户经验，也纠正片面认识。

最终目标是让用户在一次次互动里，更能掌握《毛选》中的实践论和矛盾分析方法。
